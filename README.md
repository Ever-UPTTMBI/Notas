# Sistema de Gestión de Notas

Este proyecto es un **ejercicio de prueba para estudiantes de programación**. Está diseñado para practicar conceptos fundamentales de JavaScript, específicamente:

- **Programación Orientada a Objetos (POO)**: Uso de clases para representar alumnos y el sistema de gestión.
- **Manejo de Archivos**: Persistencia de datos en formato JSON.
- **Interacción por Consola**: Uso de bibliotecas para lectura de datos en tiempo real.

## Requisitos Previos

Asegúrate de tener instalado [Node.js](https://nodejs.org/).

## Instalación

1. Clona el repositorio o descarga los archivos.
2. Abre una terminal en la carpeta del proyecto.
3. Instala las dependencias necesarias ejecutando:

```bash
npm install
```

## Uso

Para iniciar el programa, ejecuta el siguiente comando:

```bash
node notas.js
```

## Reseña del Proyecto

> "Es un ejercicio de prueba para estudiantes de programación."

Este proyecto permite:
1. Registrar alumnos (Cédula de Identidad, Nombre, Apellido).
2. Asignar y actualizar notas.
3. Calcular la nota final automáticamente.
4. Persistencia automática en el archivo `dataBase.json`.
5. Eliminar registros de alumnos.

Ideal para entender cómo se estructuran las aplicaciones de consola y cómo se gestionan los datos sin depender de una base de datos externa compleja.
